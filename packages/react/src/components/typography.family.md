## Purpose

The Typography family applies Trilogy type scales, semantic colors, and weights consistently across Web and Native.

## When to use

- Use **Title** for page and section headings that establish hierarchy.
- Use **Text** for paragraphs, labels, supporting content, and non-heading text.

## Components

### Title

A heading component with a size scale, semantic color options, and optional weight override.

### Text

A body-text component with configurable size, semantic color, and font weight.

## Composition guidance

Use heading levels in document order and choose sizes based on hierarchy rather than visual emphasis alone. Prefer semantic color tokens; reserve explicit color and weight overrides for intentional exceptions.
